# Customer Behavior Analysis

This project analyzes customer behavior using an eCommerce dataset.  
We performed **data cleaning, preprocessing, exploratory data analysis (EDA)** and created visualizations using Python (Matplotlib & Seaborn).

---

## Dataset

- `ecommerce_customer_data_custom_ratios.csv`  
  Contains customer purchase history, product categories, payment methods, age, gender, churn, and returns.

---

## Key Tasks

- Data Cleaning & Preprocessing  
- Exploratory Data Analysis (EDA)  
- Data Visualization (saved as `.png`)

---

## Visualizations

| Chart | Description |
|-------|-------------|
| `age_distribution.png` | Age distribution of customers |
| `gender_distribution.png` | Gender split |
| `churn_distribution.png` | Active vs Churned users |
| `product_categories.png` | Most popular product categories |
| `payment_method.png` | Preferred payment methods |
| `purchase_amount.png` | Distribution of total purchase amounts |
| `monthly_sales.png` | Monthly sales trend |

## Script

- `eda_visualization.py`  
  Contains all preprocessing and visualization code.
